# Приложение для контроля работы промоутеров

## Назначение

Приложение предназначено для контроля работы промоутеров на маршрутах распространения рекламных материалов.

Основные возможности:

* получение назначенных маршрутов с сервера;
* отображение маршрутов на карте;
* фотографирование выполненной работы;
* автоматическая привязка GPS-координат к фотографиям;
* работа при отсутствии интернета;
* последующая синхронизация данных с сервером;
* контроль выполнения маршрутов.

---

# Настройка приложения

## Шаг 1. Настройка адреса сервера

При первом запуске приложение требует настройки адреса API.

Для этого необходимо отсканировать QR-код со следующими данными:

```json
{
  "apiUrl": "https://example.com/"
}
```

где:

* `apiUrl` — базовый URL сервера.

Пример:

```json
{
  "apiUrl": "https://int.company.ru/"
}
```

После успешного сканирования приложение сохраняет адрес сервера и начинает использовать его для всех последующих запросов.

---

## Шаг 2. Авторизация промоутера

После настройки адреса сервера необходимо авторизовать промоутера.

Для этого нужно отсканировать второй QR-код со следующими данными:

```json
{
  "promoter_id": 123,
  "nickname": "Иван",
  "api_key": "4c9dbfa1-13ab-4f5d-91d5-8ea7cf0cbf72"
}
```

Параметры:

| Поле        | Описание                 |
| ----------- | ------------------------ |
| promoter_id | Идентификатор промоутера |
| nickname    | Отображаемое имя         |
| api_key     | Ключ доступа к API       |

После сканирования данные сохраняются локально на устройстве.

---

# Авторизация API

Для всех методов передаются заголовки:

```http
X-APP-KEY: my-promoter-app-key-v1
X-API-KEY: <api_key>
```

Проверка выполняется на сервере.

---

# Используемые API

После настройки приложение начинает взаимодействовать с сервером.

Все запросы выполняются относительно адреса, указанного в QR-коде.

Например:

```text
https://example.com/
```

---

## Проверка данных авторизации

URL:

```text
api/auth/check/
```

Метод:

```http
GET
```

Параметры:

```text
promoter_id=<promoter_id>
```

Пример ответа:

```json
{
  "success": true,
  "nickname": "Иван"
}
```

Описание:

Используется для проверки корректности сохранённых данных авторизации.

Если требуется сбросить авторизацию промоутера, то верните:

```json
{
  "code": "ACCESS_DENIED"
}
```

---

## Получение назначенных маршрутов

URL:

```text
api/my-assignments/
```

Метод:

```http
GET
```

Параметры:

```text
promoter_id=<promoter_id>
```

Пример ответа:

```json
{
  "success": true,
  "routes": [
    {
      "assignment_id": 15,
      "route_id": 8,
      "route_name": "Маршрут №8",
      "polygon": [
        [55.7522, 37.6156],
        [55.7530, 37.6200]
      ],
      "status": "assigned",
      "assigned_date": "15.01.2026 10:00"
    }
  ]
}
```

Описание:

Возвращает список активных маршрутов, назначенных промоутеру.

---

## Отправка результатов маршрута

URL:

```text
api/assignment/upload/
```

Метод:

```http
POST
```

Параметры формы:

```text
assignment_id
status
full_data_loaded
photos[]
lat[]
lng[]
has_location[]
```

Пример:

```text
assignment_id=15
status=ended
full_data_loaded=true
```

Файлы:

```text
photos[]
```

Каждой фотографии могут соответствовать:

```text
lat[]
lng[]
has_location[]
```

Пример ответа:

```json
{
  "success": true
}
```

Описание:

Используется для передачи фотографий и состояния маршрута на сервер.

---

# Работа приложения

После авторизации приложение выполняет следующий цикл работы:

1. Проверяет актуальность версии приложения.
2. Проверяет корректность данных авторизации.
3. Получает список назначенных маршрутов.
4. Отображает маршруты на карте.
5. Позволяет фотографировать выполненную работу.
6. Автоматически сохраняет GPS-координаты фотографий.
7. При отсутствии интернета сохраняет данные локально.
8. При появлении сети можно выполнить синхронизацию.
9. Передаёт фотографии и статусы маршрутов на сервер.
10. Обновляет статистику выполнения маршрутов.

---

# Требования к серверу

Сервер должен предоставлять следующие конечные точки:

```text
api/auth/check/
api/my-assignments/
api/assignment/upload/
```

Сервер должен поддерживать:

* HTTPS;
* загрузку файлов multipart/form-data;
* проверку API-ключей промоутеров;
* хранение фотографий;
* хранение GPS-координат фотографий;
* хранение назначений и маршрутов.

---

# Требования к устройству

Минимальная версия Android: Android 8.0 Oreo (API 26)

Для полноценной работы приложения необходимо предоставить разрешения:

* Камера;
* Геолокация;
* Доступ к сети Интернет.

Без доступа к геолокации фотографии будут помечаться как фотографии без GPS-координат.
